⚙ Configuración

GITHUB TOKEN

Necesario para subir tickers.xlsx directamente desde el navegador sin usar git.
Creá un token en github.com/settings/tokens → Classic → scope repo.
Se guarda solo en tu navegador (localStorage). No se envía a ningún servidor.

REPOSITORIO

facubelini/stock-screener — branch: master
El workflow se dispara automáticamente al subir el Excel.

CÓMO USAR EL UPLOAD
  1. Creá un GitHub Token con scope repo y guardalo acá.
  2. Hacé click en Subir tickers.xlsx y seleccioná tu archivo Excel.
  3. El archivo reemplaza tickers.xlsx en el repositorio.
  4. GitHub Actions corre el análisis automáticamente (~30-60 seg).
  5. El dashboard se actualiza al terminar.
